# 示例：一份填完的画像（含确认与变更记录）

> 场景同上：要在三周内交一个处理器作业，自评"对系统结构一无所知"。
> 下面五种手段都跑过一遍，去掉了个人信息。

## 1. 假设表（四选，已由学习者逐条回答）

| # | 我的假设 | 学习者回答 |
|---|---|---|
| 1 | 会二进制/十六进制互换 | 是 |
| 2 | 知道"寄存器"是 CPU 内的小存储单元 | 是 |
| 3 | 知道机器码是指令的二进制形式，没手算过编码 | 是 |
| 4 | 没写过汇编，看得懂 `add t0, t1, t2` | **更低**：指令只知道一点意思 |
| 5 | 知道 `lw/sw` 是访存 | **更低**：这两个完全没听过 |
| 6 | 时序只有模糊印象 | 是 |
| 7 | 没画过数据通路图 | 是 |
| 8 | 能读 Python，没写过中型代码 | 是 |
| 9 | 没用过 Ripes/Verilog | 是 |
| 10 | 每天 1.5–2 小时 | 是 |

## 2. 冷读测试（给 10 行真实材料，问三问）

材料：`lw t4, 0(t3)` 及其上下文 5 行汇编。

| 问题 | 回答 | 判定 |
|---|---|---|
| 这段在干什么 | "好像在取数，但不确定去哪取" | 答一半 |
| `0(t3)` 里 t3 是什么 | "不知道" | 答不出 |
| 下一条会怎样 | "t4 变了？" | 猜对，标了"猜的" |

→ 按规则：猜对按不会处理。读码判 **C**。

## 3. 术语盘点（四档）

| 术语 | 没听过 | 听过说不清 | 能解释 | 会用 |
|---|---|---|---|---|
| 寄存器 | | | ✔ | |
| PC | | ✔ | | |
| 指令/机器码 | | ✔ | | |
| 汇编 | | ✔ | | |
| lw / sw | ✔ | | | |
| 流水线 | ✔ | | | |
| mux | ✔ | | | |
| 时序 / 时钟周期 | ✔ | | | |

→ 术语 **B**（能听懂一部分名词，但项目核心词几乎全是"没听过"）。

## 4. 复述题

"寄存器是什么？" → "CPU 里存东西的格子，比内存快" —— 准确。
"一条指令怎么执行？" → "取出来、算一下、存回去？" —— 含糊。

→ 概念级能复述，机制级含糊。

## 5. 置信度

10 道里 4 道标了"猜的"，其中 3 道蒙对。→ 画像不能按卷面分记，按"确定"的记。

## 画像 v0（未确认）

| 术语 | 读码/图 | 工具 | 时序 | 元技能 |
|---|---|---|---|---|
| B | C | C | C | C |

结论：名词能听懂，但**代码和图必须逐行带**；核心术语（lw/sw、mux、流水线）等于零，
讲解时不能默认。

## Gate A 记录

学习者逐条确认了上表，只改了一条：把"术语 B"下调为"B−"，理由是 `lw/sw` 完全没听过。

```
profile v1 confirmed by user（术语 B− / 读码 C / 工具 C / 时序 C / 元技能 C）
变更记录：v0→v1，术语下调，依据=术语盘点第 5 项
```

## 复评（第 2 阶段末）

- 难度打分：刚好
- 三问：能答出两问，第三问答不上（"你卡在哪"说不清）
- 新短板：能跟着做，但说不清为什么 → 读码 C 不变，元技能仍 C
- 变更记录：无（Gate B 确认"画像不变"）

> 画像不是一次性的成绩单，是每阶段都会动的一张表。没有"变更记录"的复评，
> 等于没复评。
