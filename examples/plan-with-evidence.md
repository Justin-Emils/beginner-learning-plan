# 示例：计划每项都带依据 + 讲解按画像写

## 一、阶段表（每项标注画像依据）

画像：术语 B− / 读码 C / 工具 C / 时序 C / 元技能 C

| 阶段 | 做什么 | 依据 |
|---|---|---|
| A-1 | 只看图，不读代码；用方框画出五段 | 图示 C：先方框后细节；读码 C：不要求读代码 |
| A-2 | 背 5 个词：PC、指令、寄存器、lw、sw（每词一句人话） | 术语 B−：核心词"没听过" |
| B | 手写 5 条指令的 mux 预测，再用工具核对 | 术语升到 B 后才可以讲 mux |
| C | 在时空图上指出两处：停一拍、跳转冲掉三条 | 时序 C：先认图，不推公式 |
| D | 跑现成命令，对照预期输出 | 工具 C：给命令 + 预期，不让查 help |
| E | 只做"改了会怎样"的预测题 | 元技能 C：不要求自己设计测试 |

**写不出依据的行，删掉。** 上面每一行都能指回画像里的一条。

## 二、讲解片段（同一段内容，两种讲法）

### C 级（术语预算 3，前置声明）

```markdown
本节假设你已知道：寄存器是 CPU 里存数的小格子。
本节新词：PC、指令、lw。

PC 是"下一条指令放在内存哪个位置"的指针，像书签。
指令是内存里的一段编码，CPU 读出来照着做。
lw 是"把内存里的数搬到寄存器"的那条指令——反例：sw 是反方向，把寄存器写回内存。
```

三个新词，每个都有定义 + 例子，其中一个给了反例。没有出现 mux、流水线、时序。

### A 级（同一内容）

```markdown
PC 指向当前指令；lw 走 EX 算地址、MEM 读数据、WB 写 rd。
```

不解释、不举例——因为画像允许。

## 三、讲解自检（发布前逐条问）

- [ ] 有没有没定义的词？（C 级里出现了"内存"——但它在"本节假设"里已列）
- [ ] 有没有"显然/众所周知"？
- [ ] 例子是不是对方已经会的？（用了"书签"，他天天用）

三项全过才发出去。

## 四、如果讲深了会怎样（反例）

把 C 级那段写成：

> "PC 送 IMEM，取回的指令进 IF/ID，lw 在 EX 算有效地址、MEM 访存、WB 用 MemtoReg 选路……"

一句话里 6 个新词 + 2 个未定义的缩写，超出预算 2 倍。学习者会点头，然后什么都记不住——
这就是"讲解超出水平"的典型症状。
