## 现在这一步：A-1 · 建立"一条指令跑过五段"的画面（约 90 分钟）

### ① 看图（5 分钟）
打开数据通路图。只要能指出三件事就够：PC 在哪、五段分界在哪、五个岔口分别在哪一段。

### ② 读（约 35 分钟）
只读主教材的第 1、3、4 节，第 5 节之后先放着。

读的时候拿一张纸：
1. 把五段画成五个方框，标上每段输入/输出；
2. 在 EX 段旁画三个小三角（两个前递 mux + 一个 ALUSrc），MEM 段旁画 PCSrc，WB 段旁画 MemtoReg。

### ③ 跑（约 20 分钟）
```bash
python3 -m rvsim asm programs/sum.s                  # 地址 + 机器码
python3 -m rvsim diagram programs/sum.s --limit 16   # 时空图
python3 -m rvsim trace programs/sum.s --start 8 --end 13
```

在输出里找到这两样，找到就算学会：
- 紧跟 `lw` 的那条指令多出一个 `D` —— 那就是 load-use 停等；
- 分支成立后后面三条指令消失 —— 那就是冲刷。

### ④ 写（约 30 分钟）
新建笔记，写三句话：
1. 五段各干什么（自己的话）；
2. `lw` 后面紧跟消费者为什么要停一拍（写清"哪一段等哪一段"）；
3. 分支为什么要废掉三条。

### ⑤ 验证（判据是"能答"，不是"看完了"）
```bash
python3 -m unittest discover -s tests -q     # 应输出 OK
```
然后回答：ALUSrc=1 的指令有哪几类？ForwardB=2 的值从哪来？MemtoReg 什么时候是 1？
